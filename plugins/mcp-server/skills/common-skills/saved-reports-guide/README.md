How to author, preview, save, and edit a durable report that lives in the Drivepoint app (list_reports / get_report / preview_report / save_report). Load it the moment the user wants a report saved to the app — "save this to Drivepoint", "add it to my reports page", "edit the retention scorecard" — BEFORE you author the definition or queries, not after they say "save". It defines the query-driven contract, the preview/save flow, and the single-artifact rule.
